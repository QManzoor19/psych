# Psych

A self-paced introductory psychology course built as a single-page web app. 24 lessons across 9 units, ~700-term glossary, ~290 quiz questions, full pedagogical scaffolding, embedded videos, and 4 interactive psychology demos.

## What's inside

- **9 units, 24 lessons** covering the full intro-psych curriculum (Coon & Mitterer's *Gateways to Mind and Behavior* + an Advanced Concepts unit covering deeper Freudian, Jungian, behavioral, cognitive, and humanistic frameworks)
- **~700-term searchable glossary** with definitions
- **~290 quiz questions** filterable by unit
- **32 SVG diagrams** embedded in lessons
- **4 interactive demos**: Stroop test, reaction time, digit span (working memory), Müller-Lyer illusion
- **AI tutor tab** (Anthropic Claude integration) with floating prompt pills
- **Flashcards, badges, streaks, XP, weekly goal**
- **Video library** of curated YouTube lectures (Crash Course, TED, Sapolsky, Kahneman, etc.)
- **Notes, saved chats, Bloom's-taxonomy progress radar**

## Run locally

Open `index.html` in any modern browser. No build step.

## AI features (optional)

Add an Anthropic API key in **Settings (⚙️)** to enable the AI tutor, deep-dive generation, and AI hints. The key is stored only in your browser's localStorage.

## Stack

Vanilla HTML, CSS, JavaScript. No frameworks, no build tools. PWA-ready (`sw.js`, `manifest.json`).
